- **Blueprint APPROVED (2026-07-03)** → **architecture FROZEN.** The 10-section engineering
  blueprint and the 4-layer meta-architecture (L0 Reality → L1 Governance → L2 Knowledge →
  L3 Execution Adapters, downward-only dependencies; only L3 regenerates on tool swap) are
  ratified. Redesign is permitted only via a superseding ADR.
- **Architecture-freeze amendment rule (BINDING, owner ruling 2026-07-03).** No new
  architectural ideas post-freeze. Any architectural proposal MUST, before implementation:
  (1) identify affected ADR(s); (2) prove the existing architecture insufficient with evidence;
  (3) estimate migration cost; (4) estimate maintenance cost; (5) obtain explicit owner
  approval. Missing any of the five → rejected at intake. Applies to mid-implementation
  improvement ideas too — file as a proposal, never act inline. Interim home:
  `decision-records/README.md`; permanent home: constitution (T1.1.1) + change-approval
  policy (T1.2.1).
- **Model policy (endorsed 2026-07-03).** Default = **Opus 4.8, Effort High** for ~95% of the
  work (docs / governance E0–E2, E4–E6, E8 + most product work). Escalate to Fable 5 only for:
  (1) new architecture design (rare by construction — freeze rule); (2) whole-monorepo analysis
  (E3 T3.1.1 is the clearest candidate); (3) 50–100+ file migrations; (4) multi-hour deep
  research (T3.4.2 benchmark); (5) Opus stuck after 1–2 rounds (escalate-on-evidence). This
  policy seeds the model registry (T2.4.1).
- **Reviewer approach: pure-Claude (owner ruling 2026-07-03).** Cursor is NOT a reviewer
  (proposed ADR-0014 rejected). Isolated reviewer spawn only for high-stakes work

## Global rules

- **Cx sizing:** S ≤ half a session · M = one phase · L = must be split before work starts.
- **1 task = 1 commit = 1 review;** single-concern, independently revertible.
- **Global DoR:** (1) gating ADR is Accepted; (2) evidence floor met BEFORE writing —
  extraction reads L0 code, not docs; any behavior claim needs E1-executed evidence;
  (3) artifact nature declared (normative / descriptive / executable / evidence) → fixes the
  review route; (4) upstream merged.
- **Global DoD:** (1) header matches nature (status/version | freshness contract |
  traceability header); (2) registered in `index.yaml` if governed (from E2 on);
  (3) reviewer PASS on the nature checklist + owner ratification per the routing matrix;
  (4) commit + tracker update + memory update; repo checks left untouched-green.
- **Rollback:** text + `git revert`. Two one-way doors: file disposal → 6-step
  (Commit BEFORE Archive/Delete); blocking gates → advisory-first mandatory.
